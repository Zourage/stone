# Acceptance test 6 — 2026-09-15, the first genuinely fresh held set

Corpus 1245 sentences: **1120 train, 125 held**. Lexicon 206 entries. Script Hangul.
Bar (D50): stone → English 100% meaning-correct, English → stone ≥90% exact, every miss read by hand and grammatical; a miss that is ungrammatical or changes meaning fails the run.

## What makes this run different

Every previous run was scored on a held set that had been edited in response to test results — the objection D94 raised and D100 could only answer after the fact. This set was drawn under the rule instead of apologised for afterwards: **eligible meant never scored in a test, never corrected, and not added because a test called coverage thin.** 1029 of 1245 lines qualified; 125 were drawn in constrained random order (seed 3), accepting a line only if train kept every word at 3+ sentences and every feature at 10+. 27 of the held were written this session for thin-feature coverage and 98 are older lines no test has ever seen.

## Protocol

Eight cold agents, the 1120 train pairs as `English ||| the script` and nothing else. The held set cut into four interleaved chunks of 32/31/31/31, so each chunk spans the whole corpus by age. Chunk *k* went to two agents, one shown only the script side and one only the English side, so no agent ever saw both sides of one sentence (D75).

**One protocol deviation, in all eight agents.** The 70 KB prompt file exceeded a single Read's token cap, so every agent made two Reads of its own file instead of one, then the Write. Three tool calls rather than two. No agent read any other file, ran code, or made a web request, and all eight confirmed they ignored the project `CLAUDE.md` in their context. The materials each agent saw are unchanged by this.

## Scores

| | result |
|---|---|
| stone → English | **125/125 meaning-correct** |
| English → stone | **114/125 = 91.2% exact** |
| misses that are ill formed | 0 of 11 |
| misses that change meaning | **1 of 11** |

**Verdict: the exact-match bar is met and the run does not pass.** 91.2% clears 90% with margin, every miss parses, and the stone → English direction is perfect against the script. But one miss changes meaning, and D50 says plainly that such a miss fails the run. Calling this a pass would be reading the bar for the number and ignoring the clause next to it.

## The stone → English direction found three lines where gold was wrong

This direction has been the corpus's proof-reader since test 3, and on a held set no test had touched it earned its keep immediately. In each case the agent read the script correctly and the English beside it did not match:

- **s0327** gold said "Sort the results"; the root is 티포, whose gloss is *list*. The chunk-2 agent looked for a sort root, found none in 1120 pairs, used 티포 and flagged it. There is no sort root and none is needed — the English was simply wrong.
- **s0894** gold said "Every month the machine is measured", but the script carried no object marker, so it read as the machine doing the measuring. An agentless clause drops the subject and keeps the object marker (D65). **Both directions caught this one independently.**
- **s0137** gold's English carried a "but" with nothing corresponding in the script, which has no 채.

## The eleven misses, read by hand

**Four are corpus defects where the agent was right** (all corrected under D111):

- **s0541** "While the test runs, we should wait." Gold split the coordinated we-subject around the while-clause: `I [test run-SUB time LOC] you with wait`. All 52 other coordinated subjects in the corpus are contiguous, and D98 says the with word joining two arguments is part of the subject. **Both directions flagged this line independently** — the stone → English agent named it its single largest uncertainty without being asked.
- **s0894** as above, from the other side.
- **s0400** "I chose this one from the two." D96 says a modified anaphoric "one" takes the thing root when the English names no head; gold used the bare pronoun. The agent applied the stated rule and gold did not.
- **s0635** "How many days did it take?" D92 carves quantified duration to the measure root and unquantified to the time root; gold used the time root under a quantifier. Train **s0893** "How many weeks will the task take?" already does it the agent's way, so the corpus was teaching both.

**Six are constructions the corpus leaves undetermined.** Logged as **G35**, not decided here:

| | the two readings |
|---|---|
| s0202 "Hold the time fixed" | the control root against vary-negated; and "hold" is the standing gloss collision |
| s0559 "The part is outside" | locative predication with the hold root or the place root, both attested |
| s0565 "The part is below the machine" | region nominal with or without the possessor — D70 licenses both |
| s0699 "It is my turn" | whether "it" gets its own pronoun before the possessor |
| s0779 "Don't be alone while you fix it" | whether an embedded clause repeats a subject shared with the main clause |
| s1057 "there is no result" | the D76 true/hold ambiguity: the negative determiner or the negated predicate |

**One is a real model miss, and it is the one that changes meaning.**

- **s0730** "A hard task should be shared." Gold `타리 사세 파 레포코디 티페코` keeps the object marker, which is what makes the clause agentless (D65). The agent dropped it, giving "a hard task should share" — active where gold is passive. The construction is not thin: 17 train examples, every one consistent. This is a slip, not a corpus fault, and it is what fails the run.

## What the agents inferred

All eight independently reconstructed: head-final SOV; the postposition set (object, genitive, locative/dative, comitative, benefactive, ablative/comparative/causal, before, after); the verb template root + negation + tense + **obligatory four-way evidential** + optional attitude suffix; the question particle; `코디` as the nominaliser feeding the four modals and the while/until/since/because/become/still frames; and conditionals. Two noticed unprompted that the lexicon uses systematic vowel alternation for opposites (fast/slow, hot/cold, more/less, easy/difficult). **All eight judged it a constructed language and none read any word as Korean.** The D52 priors hold on a fifth surface.

## No word needed coining

The run produced exactly one "no root exists" report, for *sort* in s0327 — and that was the gold English being wrong, not a gap. 206 words expressed all 125 held sentences. Whatever the lexicon needs next, this run did not find it.
