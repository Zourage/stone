# Conversation test 1 — a code request between two models — 2026-09-19

Corpus 1434 sentences, lexicon 224 entries, at `4687539`. **Serves goal 1** (D125),
and is the first test of **D27**, which has stood unexamined since the beginning.

**Result: D27 holds, and more strongly than it claimed. A requirement stated in the
script survived twelve turns of conversation and produced working Python — and the
code carries a diagnosis that was reached *during* the conversation, not stated in
the requirement.** The failure is elsewhere and it is specific: **the language cannot
hand anything over.**

## Why this test exists

Tests 1–9 all score isolated sentences. None measures a conversation, which is what
D1 asks for, and none tests D27: *"once fluent from the corpus, a model takes
instructions in stone and writes code from them; no formal grammar is needed."*
That claim was made in D27 and never checked.

## Protocol

Three models, three roles, all through OpenRouter.

- **A** = `google/gemini-3.8-flash`, briefed **privately in English** as a non-programmer
  with a file of numbers who wants a count of rows over ten, who tried once and failed
  and does not know why.
- **B** = `z-ai/glm-5.3`, briefed privately as the one who writes the code.
- **C** = `x-ai/grok-4.6`, a **cold reader** translating each line with no conversational
  context and no brief. C is the honest reading.

Neither A nor B ever saw English from the other, or the other's brief. Each turn, a
model saw only the corpus, its own brief, and the script so far. Twelve turns, then A
says `에 우 파 리코디 티페카마` — *you should build it* — and B is asked for Python
with **no English gloss of the conversation at all**.

## The conversation, as C read it cold

1. **A** I have a file of numbers on the machine. I want to count the lines whose values are bigger than ten. I ran it once but it failed. I don't understand the cause. Help me.
2. **B** What did the machine say? Show me the file.
3. **A** The machine showed a message, but I did not understand it. I'll show you the file.
4. **B** Show me the message. I want to understand the message.
5. **A** I'll show you the message. Can you understand it?
6. **B** I can't understand it. Explain it to me.
7. **A** I can't explain it. I don't understand it.
8. **B** Show me the file. We want to find the fault.
9. **A** I'll show you the file. Can you find the fault?
10. **B** I'll look at the file. What is the fault?
11. **A** I don't know the fault. If you can find it, tell me.
12. **B** I found the fault. This value is text, not a number. I'll fix it.

## What held

**The requirement, precisely, in one sentence from a model that had only seen the
corpus.** Turn 1 glosses as `value ten from big-DIR-SUB line OBJ number-GEN-SUB want-DIR`
— the comparison construction, a numeral and a relative clause, composed correctly.
**C recovered it with zero context**, which is what establishes the script carried it
rather than the conversation.

**Turn 12 is a real diagnosis, not an echo.** *This value is text, not a number* is a
specific and plausible cause of a count-over-ten failing, reached through the exchange.
It matches no corpus line.

**The code.** Both models produced Python from the script alone. GLM's:

```python
def count_lines_above_ten(filename):
    count = 0
    with open(filename, 'r') as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            try:
                value = float(line)
                if value > 10:
                    count += 1
            except ValueError:
                continue
    return count
```

Run against `5, 12, 3, hello, 99, 10, 11, "", 7.5, 10.1` it returns **4**, which is
correct. Gemini's, written independently, does the same thing.

**And the `except ValueError` is the finding.** Nothing in the requirement asks for it.
It is turn 12's diagnosis — *this value is text, not a number* — carried into the
artifact. **Both models did it independently.** The language did not merely transport a
specification; it transported a conclusion reached inside the conversation, and two
models acted on it the same way.

## What broke, and it is not small

**Turns 4–7 deadlock.** *Show me the message / I want to understand it / I can't
understand it / explain it to me / I can't explain it.* Five turns and no progress.

Partly an artifact of the setup — there is no real file or message, so "show me" can
never resolve. But it exposes a real absence. **There is no way to hand anything over.**
No attachment, no *here it is*, no deixis onto an object present to both parties. Two
people who can only describe, never show. For the case this test was built on — a
non-programmer asking for help — that is the central move and the language does not
have it.

**And nobody can quote.** A says the machine showed a message and cannot say what the
message *said*, because there is no construction for quoting a string. In a real
request for help that is most of the information.

## Limits

One conversation, one topic, one model pair. A was Gemini, so Gemini reading the
transcript back as B is not a fully independent reader; GLM was B and knows what it
meant. **C is the clean evidence** — it translated every line correctly having seen
nothing but the corpus and that one line.

## Verdict

1. **D27 holds.** A build instruction given in the script produced correct code from a
   model that saw no English.
2. **More than D27 claimed:** a diagnosis reached mid-conversation survived into the
   artifact, independently, in two models.
3. **The corpus supports conversation better than expected** — turns depend on each
   other, questions get answered, a fault gets found.
4. **Two absences are now named by use rather than by audit: handing something over,
   and quoting.** Neither the coverage test nor the dictionary probe found either,
   because both test vocabulary and neither tests what a conversation needs to do.
