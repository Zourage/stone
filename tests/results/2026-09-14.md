# Acceptance test 1 — 2026-09-14

Protocol (tests/README.md, D3): a fresh agent with no file access, given only the 108 train sentences as English ||| stone pairs, asked to translate the 13 held sentences both ways and state the rules it inferred. Corpus at s0001–s0121, lexicon at 77 words. Prompt: built from `corpus/corpus.jsonl` train split verbatim.

## Stone → English (13 held)
13/13 meaning-correct. All 13 natural English; 12 match the corpus English exactly or trivially ("changed" for "altered"). A2 added "(I saw it myself)", a correct rendering of the direct evidential.

## English → stone (13 held)
12/13 exact match. The one miss, s0021 "It failed in this one": expected `ꍋ ꎿ ꑚ ꊖꋣꍲ`, got `ꍋ ꎿ ꊴ ꑚ ꊖꋣꍲ`, i.e. "it this-thing LOC fail-past-direct". Grammatical, meaning preserved, one word more explicit than the original. Near miss, not a failure.

## Rules the agent inferred
Correct: SOV; object marker; postpositions after their phrase; the verb suffix chain in order negation, tense, evidential; questions drop the evidential and end in the particle; the interrogative root before the phrase it questions, combining with person/location/with/for/time/count for who/where/how/why/when/how-many; numerals before the noun, additive, with 6 = 5+1 and 26 = 2 10 5 1; the subordinator as a relativizer.
Partly off: it read the general evidential as an optional modal rather than the fourth member of the evidential set, and grouped intend and predict with the evidentials rather than as a separate stance slot. It read "from" as "because" (one example only). It did not comment on the hold root for possession/existence; no held sentence exercised it.

## Verdict
Pass. 13/13 comprehension, 12/13 exact production with the miss a grammatical paraphrase. Weakest signals: the general evidential and the stance slot need more contrasting examples; the hold root and equatives are untested.

## Caveat
The agent was a subagent of the same model family running in this project, isolated by prompt (no tools, told to ignore project instructions) rather than by infrastructure. It used zero tool calls. A stricter run would use a session with no repository attached.
