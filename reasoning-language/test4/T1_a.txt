꺄 기팡 .
1: 고 터힘 사 ( 처 우투 차 각 로 처 키터 차 낙 ) 세 내 터힘욱 .
2: 고 해 거방 사 쑤탕 차 닥 서 뻬룹 라 다쿡 .
3: 고 해 구굴 사 닥 새 { 하 죠 째츰 새 조롭 차 막 라 다쿡 } .
4: 고 댜 3 저 추술 새 각 .
채 각 5: 구 뼈 챠 낙 해 지싱안 사 여 쁘칸 새 { 째츰 새 막 } .
채 낙 6: 겨 때 5 뾰 째 지싱안 사 각 새 묘 디훅 .
채 낙 7: 겨 바 ( 드론 래 각 ) 새 { 째츰 새 막 셔 미 페린 } .
채 각 8: 겨 땨 7 해 버흥 사 아 새 채둡 샤 뻬룹 라 다쿡 셔 빠좃 랴 2 가숩 .
9: 고 도 프믁 사 ( 각 로 낙 ) 새 하툰 래 각 세 누펏 .
10: 고 러존 사 ( 각 로 낙 ) 새 { 해 버흥 사 누펏 새 채둡 샤 나 뻬룹 } .
11: 고 댜 10 저 서맛 사 ( 각 로 낙 ) 새 { 해 깨춘 사 누펏 새 부릇 } .
12: 고 어착 사 각 류 레븟 사 낙 .
채 각 13: 깨 챠 낙 카슥 .
채 낙 14: 깨 챠 각 구큭 .
채 각 15: 기 마솝 새 누펏 셔 츠킁 라 세홋 수 { 쩌납 사 누펏 새 부릇 } .
채 낙 16: 그 호탓 사 으 새 포촘 라 노깁 셔 처 퍼고수아 세 터힘욱 .
채 각 17: 기 뻬 기힌 사 아 새 라훅 셔 처 퍼고수아 .
18: 고 주 차힌 새 ( 각 로 낙 ) .
