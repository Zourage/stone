# Answers (reader A)

## Text R1

1. The server (called S) crashed 4 times, this night (tonight).
2. The server's log showed that memory was almost full before every crash.
3. A team (called D) deployed a new version (called M) of the program, 2 days ago.
4. No. The sentence opens with TOLD plus the handle of another party (person B): someone else said so and the writer has not checked it.
5. That the cache (C) caused all 4 crashes. Strength: likely (probably), not certain. It is derived from sentences 3, 5 and 6: memory was almost full before every crash, version M stores all requests in the cache, and the cache has no size limit.
6. The writer has not yet measured the size of the cache. The writer plans to measure it and then report to team D.
7. (10) Team D should undo (roll back) the deployment of version M before tonight; purpose: so that the server does not crash again. (12) In addition, later, team D should configure the cache's new setting (the defined word) to 5000.
8. The maximum count of requests that the cache is allowed to store (a cache request limit).
9. Person B (the same party who reported the deployment) asks: "Must I restart the server now?" Answer: no, you do not have to restart it, because the server always restarts itself after a crash.
10. Sentence 2: "crash". Sentence 3: "log". Sentence 5: "cache". Sentence 13: "restart".
11. Sentence 6: "The cache has no size limit." (observed directly). Sentence 14: "No, you don't need to restart the server, because it always restarts itself after a crash."
