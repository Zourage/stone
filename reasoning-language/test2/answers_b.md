# Answers (reader B)

## Text R1

1. The server (handle A) crashed 4 times, this night (tonight).
2. The server's log showed that memory was almost full before every crash.
3. A team (handle D) deployed a new version (handle M) of the program, 2 days ago.
4. No. The sentence opens with TOLD (개) plus the handle of a person (N): another party says so and the writer has not checked it.
5. That the cache (handle P) caused all 4 crashes. Strength: likely/probably. It is derived from sentences 3, 5 and 6 (memory almost full before each crash; the new version stores every request in the cache; the cache has no size limit).
6. The writer has not yet measured the size of the cache. The writer plans to measure it and then report to the team.
7. (10) That the team undo (roll back) the deployment of the new version before tonight, so that the server does not crash again. (12) In addition, that the team later configure the cache's maximum request count to 5000.
8. The spare word means "the largest count of requests that the cache may store", i.e. the cache's maximum number of entries (its request limit).
9. The person N (the one who reported the deployment) asks: "Must I restart the server now?" Answer: no, you do not have to, because the server always restarts itself after a crash.
10. Sentence 2: "crash". Sentence 3: "log". Sentence 5: "cache". Sentence 13: "restart".
11. Sentence 6: "The cache has no size limit." (observed directly). Sentence 14: "You don't need to restart the server, because it always restarts itself after a crash."
