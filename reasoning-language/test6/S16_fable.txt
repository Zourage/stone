꺄 미작 래 ( 쏘날 라 데잣 ) 러 ( 빼듭 2000 치 2004 ) .
화 사붕 회 무섭 라 { 떠링 라 배컴 사 어 새 어 쎄 처님 } .
1: 겨 삐 지싱 사 아 새 마 싸낫 래 미 오덕엄 류 하 프믁 사 아 새 싸낫 소 치팃 .
2: 겨 삐 세 마 찌킥 베봇 사 ( 더빔 라 키틀음 ) 새 ( 토신음 래 아 ) .
3: 겨 삐 투 토신 새 아 스 ( 사툭 라 떠못 ) 슈 스 ( 빼듭 로 루몹 ) .
꺄 추축 1 러 처 «ILOVEYOU» .
4: 거 바 해 저 띠톨 새 사붕 차 각 라 처 «ILOVEYOU» 셔 ( 페린 라 처 루아 래 빼듭 2000 ) 서 처 «Philippines» .
5: 거 바 해 띠톨 새 각 쎄 이루오처 라 { 캐촉 새 어 슈 쑤탕 라 제박 } .
6: 거 바 되 { 해 데심 사 쁘칸 새 츠춧 래 이루오처 } { 해 버흥 사 각 새 떠링엄 래 각 샤 마 치먹 라 { 거긍 사 므 쁘칸 새 어 } 류 해 서증 사 각 새 먀 츠춧 } .
7: 겨 두 6 해 노함 사 각 새 ( 깨춘 래 쁘칸 ) 류 댜 하 탸 지쿱 랴 ( 채돗엄 래 사붕 ) 새 각 .
8: 거 배 해 떠절 사 각 새 누 10000000 쏘벌옹 쌔 며 츠킁 .
9: 거 배 하 해 해춤 사 처 «Philippines» 새 오덕일 래 각 쇼 { 하 해 헤즌 새 ( 꺼폿 스 ( 떠뭉 라 쏘벌옹 ) ) } 류 도 해 크첨 사 처 «Philippines» 새 꺼폿 라 므 빼킷 .
10: 거 댜 바 해 저 츠학 사 ( 무섭 라 이루오처 ) 새 츠춧 라 에잔앱 래 이루오처 류 해 머덤 사 먀 제볼일 새 { 캐 하 데심 사 제볼일 새 츠춧 라 까름안 } .
꺄 추축 2 러 처 «Code Red» .
11: 거 바 해 띠톨 새 사붕 차 낙 라 처 «Code Red» 셔 ( 페린 라 처 제처아 래 빼듭 2001 ) .
12: 거 바 해 떠절 사 낙 새 삐필옹 라 트질 라 { 해 크첨 사 뻬룹 차 삭 라 처 «Microsoft» 새 무섭엣 래 어 } 류 하 해 노함 사 낙 새 ( 깨춘 래 쁘칸 ) .
13: 거 바 해 제볼 사 낙 새 너텁 라 { 죠 해 페튼 사 삭 새 쩌납엄 수 어 셔 노축 랴 낙 쌔 네 1 페린 } .
14: 거 배 해 떠절 사 낙 새 누 300000 삐필옹 쌔 뉴 1 츠킁 .
15: 거 바 해 느참 사 낙 새 트질 래 ( 삐필옹 라 떠절엄 ) 류 해 켜 세닌 사 낙 새 트질엣 래 ( 라덜엣 래 처 «USA» ) .
16: 갸 13 14 하 해 투절 사 먀 아빔일 래 삐필옹 새 쩌납엄 라 세범 류 댜 캐 투절 라 꺼득 사 마 아빔일 새 쩌납엄 .
꺄 추축 3 러 처 «SQL Slammer» .
17: 거 바 해 띠톨 새 사붕 차 닥 라 처 «SQL Slammer» 셔 ( 페린 라 처 주테우가 래 빼듭 2003 ) .
18: 거 바 해 떠절 사 닥 새 삐필옹 라 ( 거긍 라 거통 ) 라 { 해 크첨 사 삭 새 무섭엣 래 어 } 소 너텁 라 { 죠 해 페튼 사 삭 새 쩌납엄 수 어 셔 노축 랴 닥 쌔 네 6 페린 } .
19: 거 배 쎠 네 8.5 흐훗 해 저 2 티 떠못 새 세필엄 래 ( 쏘벌옹 라 떠절엄 ) 슈 세필엄 라 세홋안 .
20: 거 배 해 떠절 사 닥 새 매 삐필옹 라 { 우놀 사 어 새 너텁 } 러 ( 네 75000 삐필옹 ) 쌔 네 10 쏘섭 .
21: 거 댜 바 해 저 꺼득안 새 데잣 세 먀 써공 류 해 제 메훌 사 메 매십 라 채둡 래 누펏 류 해 자덤 새 메 태탓 .
꺄 추축 4 러 처 «Blaster» .
22: 거 바 해 띠톨 새 사붕 차 막 라 처 «Blaster» 셔 ( 페린 라 처 우에베허쩌 래 빼듭 2003 ) .
23: 거 다 18 바 해 떠절 사 막 새 패 쏘벌옹 라 { 제볼 사 어 새 ( 어혼 라 처 «Windows» ) } 세 ( 터힘욱 로 메훌욱 ) .
24: 거 바 하 해 노함 사 막 새 ( 깨춘 래 쁘칸 ) 류 해 파킨 사 막 새 { 먀 쨔 제 메훌 사 쏘벌옹 라 떠절엄 } .
25: 거 바 죠 해 페튼 사 삭 새 쩌납엄 셔 노축 랴 막 쌔 네 1 페린 .
26: 거 배 해 켜 세닌 사 막 새 트질엣 라 { 수랍 사 어 새 때붐엄 래 삭 } .
꺄 추축 5 러 처 «Sasser» .
27: 거 배 해 저 띠톨 새 사붕 차 박 라 처 «Sasser» 셔 ( 드즘 랴 ( 페린 라 처 우뻐고처 래 빼듭 2004 ) ) .
28: 거 바 게츤 랴 막 새 박 스 ( 머롤 래 띠톨 ) 류 해 자덤 사 박 새 ( 메 태탓 로 메 따킹 ) .
29: 거 배 죠 해 페튼 사 삭 새 쩌납엄 셔 노축 랴 박 쌔 며 가숩 .
30: 거 바 해 오덕 사 쁘칸 라 처훈 래 처 «Germany» 새 박 류 해 써물 사 도칸 새 므 쁘칸 셔 ( 페린 라 처 루아 래 빼듭 2004 ) .
꺄 추축 6 러 쁘삽엄 .
31: 겨 삐층 사 먀 쁘칸 새 { 해 제볼 사 ( 사붕 라 떠못 ) 새 너텁 라 뻐복 } .
32: 갸 13 18 25 29 땨 31 죠 해 헤즌 새 쩌납엄 셔 노축 랴 ( 낙 로 닥 로 막 로 박 ) 류 하 해 투절 사 먀 쁘칸 새 쩌납엄 .
33: 거 배 셔 빼듭 2003 해 저 1 쨔 페튼 사 삭 새 쩌납엄 쎠 페린 소 까딥 라 소층 .
34: 거 바 셔 빼듭 2004 해 페튼 사 삭 새 때붐엄 라 떠못 수 처 «Windows» 류 세 미 때붐엄 토칵 새 무섭 라 { 츠학 사 어 새 뻬함 서 깨믓안 } 시 투믕 .
35: 겨 듀 캐 꺼득 새 ( 투절 래 쩌납엄 ) 류 캐 빠식 새 ( 포점엄 라 투믕 ) 류 캐 하 드풋 사 제볼일 새 ( 츠춧 라 까름안 ) .
